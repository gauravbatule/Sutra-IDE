The AI‑native IDE that builds with you

A chat-first IDE where Astra, your built-in agent, plans and ships real work alongside you. Multi-model routing across GPT‑5, Claude 5, Gemini 3, GLM, Grok, DeepSeek, NVIDIA NIM and Ollama — bring API keys or just session cookies.

Features

Everything you need, nothing in the way

Chat-first manager mode

Drive your whole project from a single conversation, then drop into the full IDE — editor, terminal, git and preview are always one click away.

Astra autonomous agent

Astra reads, writes and runs your codebase end to end. Choose Strict mode for reviewed changes or Full Access when you want it to move fast.

45+ built-in tools with approvals

File edits, shell commands, search, browser checks and more — every sensitive action surfaces a clear approve-or-deny prompt before it runs.

Multi-model failover

Pick any provider from one dropdown. When a model rate-limits or drops, SUTRA hands your in-flight work to the next available model automatically.

Image understanding & generation

Drop in screenshots, mockups and diagrams for Astra to reason about, and generate production-ready visuals with dedicated image models.

Mobile companion via QR

Scan a QR code to pair your phone. Check on long-running tasks, reply to Astra's questions and steer builds from anywhere.
