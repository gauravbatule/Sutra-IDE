# Security Policy

## Supported Versions

We actively maintain and provide security updates for the following versions of SUTRA IDE:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The security of SUTRA IDE and its users' local machines is taken very seriously.

If you discover a security vulnerability or sensitive bug:
1. **Do NOT open a public GitHub issue.**
2. Report the vulnerability privately to Gaurav Batule via GitHub security advisory or email.
3. Include:
   - A detailed description of the vulnerability.
   - Steps to reproduce or proof-of-concept code.
   - Potential impact and affected components (e.g. tool sandbox, local server, WebSocket bridge).

We will review the issue promptly, validate the findings, and coordinate a patch release.
